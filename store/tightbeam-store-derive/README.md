# tightbeam-store-derive

The `#[derive(Storable)]` and `#[derive(Catalog)]` macros of [tightbeam-store](https://crates.io/crates/tightbeam-store). Depend on `tightbeam-store`, which re-exports both.

Implementation: [docs/store.md](https://github.com/wahidgroup/tightbeam-ext/blob/master/docs/store.md#declare-a-type).
