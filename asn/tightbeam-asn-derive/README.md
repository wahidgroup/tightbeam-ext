# tightbeam-asn-derive

Proc-macro crate for [`tightbeam-asn`](https://github.com/wahidgroup/tightbeam-ext/tree/master/asn/tightbeam-asn). Depend on `tightbeam-asn`, which re-exports `AsnCodec` for Sequence, Enumerated, and Choice DER types. Implementation: [docs/asn.md](https://github.com/wahidgroup/tightbeam-ext/blob/master/docs/asn.md#derive).
