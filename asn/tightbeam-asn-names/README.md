# tightbeam-asn-names

The TypeScript type-name rule that [`tightbeam-asn`](../tightbeam-asn) and [`tightbeam-asn-derive`](../tightbeam-asn-derive) share, so the derive and the emitter admit the same names. Depend on `tightbeam-asn`, which applies the rule for you. Implementation: [docs/asn.md](../../docs/asn.md#type-names).
