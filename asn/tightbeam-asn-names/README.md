# tightbeam-asn-names

The TypeScript type-name rule that [`tightbeam-asn`](https://github.com/wahidgroup/tightbeam-ext/tree/master/asn/tightbeam-asn) and [`tightbeam-asn-derive`](https://github.com/wahidgroup/tightbeam-ext/tree/master/asn/tightbeam-asn-derive) share, so the derive and the emitter admit the same names. Depend on `tightbeam-asn`, which applies the rule for you. Implementation: [docs/asn.md](https://github.com/wahidgroup/tightbeam-ext/blob/master/docs/asn.md#type-names).
