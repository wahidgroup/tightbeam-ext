# Security Policy

## Supported Versions

Only the latest published release of each extension receives security updates: `tightbeam-wire`, `tightbeam-ws` and its client, `tightbeam-grpc`, `tightbeam-pubsub` and its client, and the `tightbeam-asn` crates.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest release | :white_check_mark: |
| Older releases | :x:                |

## Reporting a Vulnerability

Report security issues **privately** via GitHub Security Advisories:

https://github.com/wahidgroup/tightbeam-ext/security/advisories/new

Do **not** open a public GitHub issue, pull request, or discussion for security reports.

Include as much of the following as possible:

- Description of the issue and its potential impact
- Affected crate or package version(s)
- Steps to reproduce
- Suggested fix or mitigation (if known)
